i Installation Instructions

Prerequisites: .NET Desktop Runtime 6.0

Already have the game? Use Download → Find Existing Install, or open Settings and browse for your game folder — then continue from the steps below.

  1. Download game files

    Click Download here in the launcher and wait for the install to finish. The files are set up for AntHill LIVE (AHL) by default.

  2. AntHill LIVE account (for online play)

    a. First sign up: login.shadowrunfps.com/signup.srf

    b. Create your gamertag: xbox.shadowrunfps.com:8090/NewGamertag.srf

    • Email is case-sensitive in-game.
    • Password MUST be 15 characters or less.
    • Save email/password — there is no recovery flow. Any email works if you can remember it at login.
  3. Launch & sign in

    Click Play in this launcher. When the game opens, sign in with your AHL email and password. For offline or bots only, choose Create Local Profile.

  4. GFWL only — Activate Game

    Skip this step if you only use AHL.

    Classic Xbox LIVE online only: launch Shadowrun → sign in until the activation screen appears → then click Activate Game in the launcher (not sooner). When fully signed in online, quit Shadowrun fully and relaunch.

Before you play

In-game (main menu only — not during a match): open Video → Advanced and turn V-Sync off (leaving it on caps FPS at 30). Set Input to Default for mouse and keyboard or Gamepad for a controller. Non-Xbox controllers — see the troubleshooting guide.

Dedicated server: In-game: Public Matches → Dedicated Servers → Find All → Shadowrun Official Server.

AntHill LIVE vs GFWL: Settings → Open Diagnostics → Server Configuration (toggle at the top):
On = AntHill LIVE community servers
Off = Microsoft’s classic GFWL endpoints (online play uses Activate Game; AHL does not)
