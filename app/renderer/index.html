Installation Instructions

Already have the game installed? Click Download → Select Existing Game, browse to your game folder, then continue from step 2 (Launch Game First).

Follow these steps to install and activate Shadowrun (10-15 min).

  1. 📥 Download & Install

    Click "Download" and wait for all components to install (game files, GFWL, DirectX 9). You'll see progress indicators for each component.

  2. 🚀 Launch Game First

    Once installation completes and you see the "Play" button, click it to launch the game at least once. This initializes required files.

  3. 🔐 Activate Game

    Close the game, then click "Activate Game" in the launcher. Allow administrator permissions when Windows prompts you (UAC dialog).

    Note: This step is only for GFWL-enabled installs (retail / Games for Windows Live). If your build does not use GFWL, you can skip launcher activation.

  4. 🎮 Launch & Sign In

    Click "Play" to start Shadowrun. When the Games for Windows Live (GFWL) sign-in window appears, sign in with your Xbox Live account.

  5. ✅ Complete Setup

    Once you reach the main menu, close the game completely. You can now relaunch and play normally!

⚠️ Important Notes:

  • First Launch: Always close the game after your first successful login, then relaunch to begin playing.
  • After Activation: Failure to close the game first after activating may lead to connection issues in a small number of cases. Always close the game completely after activation before launching again.
  • Offline Sign-In: If you see "Signed in offline" when launching, close the game and run the activation steps again.
  • Admin Rights: The launcher may need administrator permissions for activation. Right-click and "Run as Administrator" if prompted.

💡 Pro Tips:

  • Launch the game at least once before activating to ensure all files & PCID are initialized
  • Run the launcher as Administrator if you encounter any activation issues
