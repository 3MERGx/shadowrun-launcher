Installation Instructions

Follow these steps to install and activate Shadowrun (10-15 min).

  1. Download & Install: Click "Download" and wait for all components (game files, GFWL, DirectX 9) to install.
  2. Launch Game: Once complete, click "Play" to start Shadowrun.
  3. Sign In: When GFWL appears, sign in with your Xbox Live account (create one if needed).
  4. Product Key Screen: Continue until you see the product key screen.
  5. ⚠️ Important: Press Alt + Tab to return here. Do NOT close the game.
  6. Activate: Click "Activate Game" and allow admin permissions when prompted.
  7. Return: Switch back to Shadowrun with Alt + Tab.
  8. Complete: Product key should auto-fill. Once at main menu, you're done!

💡 Tips:

  • Launch game at least once before activating
  • Keep game running during activation
  • Run launcher as Administrator if issues occur
